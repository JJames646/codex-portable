# 已确认与待确认问题

更新时间：2026-07-16

## 已确认

1. 正式客户端使用 Rust + Tauri 2 + React + TypeScript，把 Codex++ 能力整合到当前工作站 UI。
2. 目标系统是 Windows 11 x64，第一块测试移动存储容量为 64GB。
3. Codex 只能从移动盘中的工作站启动台启动。
4. 工作站授权不要求注册账号，采用卡密激活。
5. 卡密有效期从首次激活开始，不支持退款。
6. 工作站服务暂定约 ¥99，独立卡密暂定 ¥10。
7. 一个卡密允许绑定多台工作站，但具体上限由后台配置。
8. 用户在中转站网站复制 API Key，在工作站粘贴框中粘贴后自动填写预设供应商。
9. 首页主仪表盘使用 Codex++ 概览数据，中转站用量作为已配置后的附加模块。
10. 不使用 PIN 或工作站解锁密码。
11. 恢复出厂设置删除全部用户数据、凭据、卡密、项目、会话、插件、Skills、备份和缓存。
12. 每次插入并启动时自动检查自己的 GitHub Release 更新清单。
13. 用户允许创建所需 GitHub 项目，并允许后续通过 SSH 连接 Win11 电脑调试。
14. 用户接受向接收者提供 Codex++ 对应修改源码，正式客户端继续采用 AGPL Codex++ Fork。
15. 开发按正常顺序先生成用户本人测试版，在 Win11 和移动盘验证后，再生成附带对应源码的发行候选版；最终产品不只限于内部使用。

## 已解除的商业发布阻断项

- Codex++ AGPL 对应源码问题已经确认接受。
- 客户端可以收费分发，但每个二进制发行版必须向接收者提供准确对应的源码、构建说明和许可证。

## 不阻止阶段 1、但必须在载荷发布前确认

1. 是否已获得便携 Codex/桌面应用载荷的商业再分发许可。

## 必须在卡密与后台阶段前确认

1. ¥99 具体包含永久客户端、固定期限服务、移动存储硬件，还是组合产品。
2. ¥10 卡密的有效期是否固定为 30 天。
3. 每张卡密默认最大绑定数量。
4. 是否允许用户自助解绑，还是只能管理员解绑。
5. 卡密达到绑定上限后，更换损坏 U 盘的处理规则。
6. 套餐到期时，是立即停止正在运行的 Codex，还是停止新模型请求并提示切换供应商。

## 必须在服务器阶段前确认

1. Sub2API 的正式域名、测试域名和部署区域。
2. 是否已有合法可用的模型 API/企业账号。
3. activation-bridge 与 Sub2API 通过管理 API 还是受信任内部接口对接。
4. “官方中转站”的最终品牌名称，避免产生 OpenAI 官方运营的误解。
5. 完整网站详情使用独立远程 WebView，还是允许系统浏览器作为降级。

## 必须在连接服务阶段前确认

1. 自有接入网关和 CDN 是否支持 SSE/WebSocket。
2. 用户实际只访问本产品自有 API，还是还要求访问第三方网站；后者不属于当前范围。
3. 套餐用户权益与独立卡密权益的优先级。
4. 服务器、CDN、支付、数据和经营合规要求。

## 必须在数据阶段前确认

1. “Scale 记忆”具体指哪个产品、文件或数据库。
2. 无 PIN 模式的安全提示文案和用户确认方式。
3. 默认推荐 NTFS，是否仍正式支持 exFAT。
4. 完整恢复出厂设置是否需要提供一次可选导出机会；执行后仍然全部删除。
5. 第三方 OAuth 需要重新登录时的提示和容忍范围。

## 必须在发布前确认

1. 产品最终名称、图标和非官方声明。
2. Codex++ 对应源码仓库、Release tag、构建说明和 AGPL 材料。推荐使用公开 GitHub Fork。
3. 便携桌面载荷的再分发结论。
4. Sub2API 商业使用和上游服务条款结论。
5. 隐私政策、用户协议、不退款规则和服务可用性说明。
6. Windows 代码签名证书的持有人和采购方式。
